# 示例

这里放的是**比对用的历史样例**，不是可直接复制的模板，也不是输出契约。

## 内容

| 文件 | 类型 | 怎么用 |
|---|---|---|
| `01-04-*.zh-CN.md` | 真实案例复盘 | 看结构取舍、语气和节奏，用于比对新方案是否偏航 |
| `homepage-golden-sample.zh-CN.json` | 首页蓝图样例 | 看一份合格蓝图的字段组织方式；它引用的蓝图 schema 已移入仓库 `archive/legacy-layers/protocols/`（不随包发行），所以只作表达参考 |
| `product-detail-golden-sample.zh-CN.json` | 产品详情蓝图样例 | 同上 |

## 注意

- 样例里出现的模块名（如 `brand-hero`）来自已归档的模块 recipe，当前技能不再强制这套模块库。
- 样例中的产品、材质、报价信息是示例数据，**不能当作真实产品事实引用**。
- 规范本身的唯一真源是仓库根目录 `DESIGN.md`。
