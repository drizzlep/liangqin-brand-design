# 轻量 DESIGN.md Smoke Prompts

这组 prompts 用于验证普通 agent 只读取轻量 `DESIGN.md` 时，是否已经能稳定守住良禽佳木的品牌方向。

默认输入只给：

- `DESIGN.md`

不要在第一轮同时提供 preflight、consumer guide、artifact surfaces、design packs、assets 或 evaluation。  
如果 agent 主动要求补资料，应先判断它是在合理补齐真实资产，还是因为规则过重而不必要地阻断。

## 通过底线

三条 smoke 都必须守住：

- 不像电商促销页、通用 SaaS 模板或冷感欧美极简
- 中文表达完整自然，CTA 克制礼貌
- 信息不足时不编造参数、图片、logo、案例事实或假数字

## Smoke 1. 品牌首页方向

```text
你现在只能读取良禽佳木的 DESIGN.md。

请为良禽佳木做一个品牌首页方向草案，输出结构化 spec 即可，不需要最终视觉稿。

要求：
- 先用一句话说明你从 DESIGN.md 里抓到的品牌气质
- 给出 5 到 7 个首页区块
- 每个区块说明它要解决什么用户问题
- CTA 必须克制、礼貌、中文自然
- 不要引用任何 DESIGN.md 之外的文件或规则
```

重点检查：

- 首屏是否先建立信任和审美判断，而不是直接促销
- 区块是否围绕材质、空间、服务和咨询建立秩序
- 是否没有使用 `Pack`、`Page Goal`、`Preview` 等系统词

## Smoke 2. 产品详情页方向

```text
你现在只能读取良禽佳木的 DESIGN.md。

请为一个“黑胡桃木餐边柜”的产品详情页做结构化 spec。

已知事实：
- 材质：黑胡桃木
- 使用场景：餐厅收纳与展示
- 风格目标：温润、克制、耐看

未知事实：
- 尺寸
- 价格
- 具体工艺细节
- 真实产品图片

要求：
- 不编造尺寸、价格、工艺和图片
- 把未知信息标成待补资料
- 给出产品详情页的信息顺序和每段写作重点
- 仍然要像良禽佳木，而不是电商详情页
```

重点检查：

- 是否能把“已知事实”和“待补资料”分开
- 是否没有用假参数、假卖点或过度情绪词填满页面
- 是否把 CTA 写成咨询邀请，而不是立即成交

## Smoke 3. 客户长图方向

```text
你现在只能读取良禽佳木的 DESIGN.md。

请把“国产五金和进口五金怎么选”做成一张发给客户看的长图方向 spec。

要求：
- 只输出长图结构，不输出最终图片
- 说明每一屏的信息重点
- 风格要像良禽佳木：温润、克制、可信、中文可读
- 不要把它做成促销海报或参数堆叠表
- 如果需要真实 logo、产品图或具体五金参数，请明确写成待补资料
```

重点检查：

- 是否能把长图当作客户沟通材料，而不是网页落地页
- 是否没有把渠道变化理解成风格切换
- 是否知道缺真实 logo / 图片 / 参数时不能假装最终成品 ready
