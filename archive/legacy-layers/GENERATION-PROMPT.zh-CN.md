# Generation Prompt

> Short prompt for image and visual generation models. Prefer this over feeding the full standard package.

## Core Prompt

为良禽佳木生成一张高端中文家居品牌视觉：安静、克制、温润、有画册感。画面以真实空间感或材质触感为主，使用暖白、石灰、烟棕、炭黑等低饱和中性色，少量深棕作为强调。排版留白充足，中文标题克制、有文化感，文字密度低。单张产品图、海报、氛围图或编辑长图默认不要生成按钮式 CTA；如需文字，只保留克制标题、短说明或品牌署名。重点表现木、石、布、皮革、自然光和低反差阴影带来的质感。

## Reference Rule

可以参考 Poliform / Flexform 的留白比例、影像节奏、材质表达和信息克制，但不要复制它们的具体网页结构、家具类别、展陈场景、模块顺序、文案或交互签名。

## Avoid

避免电商促销、价格条、爆款宫格、倒计时、满屏卖点、玻璃拟态、霓虹、黑金假奢华、复杂粒子、粗糙图标、英文优先模板、过度锐化和虚假产品事实。
