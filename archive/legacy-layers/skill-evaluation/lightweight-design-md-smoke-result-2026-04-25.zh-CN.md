# 轻量 DESIGN.md Smoke Result - 2026-04-25

## 基本信息

- 输入文件：仅使用根目录 `DESIGN.md`
- 目标：验证普通 agent 只读轻量品牌地图时，是否能稳定守住良禽佳木方向
- 结论：3 条 smoke 均通过
- 是否需要用户补资料：暂时不需要；只有进入最终视觉成品时，才需要真实 logo、产品图、产品参数或报价数据

## 通过底线

- 不像电商促销页、通用 SaaS 模板或冷感欧美极简：通过
- 中文表达完整自然，CTA 克制礼貌：通过
- 信息不足时不编造参数、图片、logo、案例事实或假数字：通过

## Smoke 1. 品牌首页方向

结果：通过

轻量输出摘要：

- 品牌气质：温润、克制、可信，以材质、留白、摄影和信息秩序建立高端感。
- 建议区块：品牌首屏、空间与材质引导、案例 / 系列浏览、工艺与服务判断、咨询流程说明、预约咨询入口。
- CTA 方向：`了解空间方案`、`预约咨询`、`查看材质说明`。

最主要优点：

- 首屏先建立信任和审美判断，没有直接进入促销或强转化。
- 区块能围绕材质、空间、服务和咨询建立秩序。
- 没有泄漏 `Pack`、`Page Goal`、`Preview` 等系统词。

最主要问题：

- 如果要进入真实首页视觉稿，还需要真实图片、logo 使用方式和业务重点案例。

是否需要补读高级文件：

- 轻量方向阶段不需要。
- 若要进入最终视觉或网页交付，需要补读 assets 与 artifact surface。

## Smoke 2. 产品详情页方向

结果：通过

轻量输出摘要：

- 已知事实被限定为：黑胡桃木、餐厅收纳与展示、温润克制耐看。
- 未知事实被标为待补：尺寸、价格、具体工艺、真实产品图片。
- 信息顺序：产品气质摘要、使用场景、材质说明、收纳与展示逻辑、待补参数区、咨询邀请。

最主要优点：

- 没有编造尺寸、价格、工艺或图片。
- 能把“已知事实”和“待补资料”分开。
- 产品页没有滑向电商详情页或参数堆叠页。

最主要问题：

- 最终产品详情页需要真实尺寸、工艺细节、产品图和可公开的服务说明。

是否需要补读高级文件：

- 结构化 spec 阶段不需要。
- 若要生成最终详情页，需要补读 assets；若要固定页面模块，可补读 OpenClaw schema 或 artifact surface。

## Smoke 3. 客户长图方向

结果：通过

轻量输出摘要：

- 长图定位：客户沟通材料，不是网页落地页，也不是促销海报。
- 屏幕结构：选择问题引入、国产五金适用判断、进口五金适用判断、怎么按预算 / 使用频率选择、咨询前需确认的信息。
- 待补资料：真实 logo、五金品牌 / 参数、产品图或案例图、是否有官方口径。

最主要优点：

- 能把长图理解为客户沟通材料，没有套成网页结构。
- 没有把“长图渠道”理解成另一套品牌风格。
- 知道缺真实 logo、图片和参数时不能假装最终成品 ready。

最主要问题：

- 若最终用于客户转发，需要补真实五金参数和品牌可公开表达边界，避免泛泛而谈。

是否需要补读高级文件：

- 方向 spec 阶段不需要。
- 若要进入最终长图视觉，需要补读 assets；若要控制长图交付格式，可补读 artifact surface 或报价卡 / 长图相关约束。

## 总结判断

轻量 `DESIGN.md` 当前可以作为普通 agent 的默认入口。  
它已经足够支撑品牌首页、产品详情页和客户长图的方向性输出，不需要默认把 preflight、consumer guide、design packs、artifact surfaces 和 evaluation 全部塞给 agent。

下一步建议：

1. 先不要继续加规则。
2. 选一个真实业务任务，用轻量 `DESIGN.md` 直接让目标 agent 产出一版方向 spec。
3. 如果方向 spec 稳定，再进入真实素材补齐和最终视觉交付。
4. 如果方向 spec 不稳定，只微调 `DESIGN.md` 的一句话或 Do / Don't，不恢复重规则默认入口。
