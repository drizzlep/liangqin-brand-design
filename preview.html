Overview 概览

品牌锚点：以温润克制的高级感与理性秩序感，服务中文语境下重视品质、可信度与审美耐久度的客户。

温润克制高定 理性安静耐看

纹理来自真实摄影中的木、石、布、皮革；UI 结构保持平整简洁。留白充足且有方向感，不做均匀铺满。

是

安静、克制、画册感强；先建立审美高度与信任，再承接产品与咨询。

不是

促销页、冷感国际模板、炫技动效；也不复制参考品牌的结构与交互签名。

Reference notes · 展开规范补充

Do's and Don'ts 该做与不该做

Do

  • 先建立品牌气质与信任，再谈产品与咨询入口
  • 用真实摄影、材质、比例与留白表达高级感
  • 中文可读性优先：字号、行高、标签完整度
  • 结构稳定、允许有限变化
  • 信息不足时给 spec、占位或待补清单

Don't

  • 电商促销风、倒计时、夸张稀缺文案
  • 冷感国际模板腔、玻璃拟态、炫技动效
  • 低质量图标、假数据、编造参数或案例
  • 照搬参考品牌的结构、形态与交互签名
  • 用纯文字品牌名冒充 logo

Responsive Behavior 响应式

Mobile

0-767px · 4 栏 · 槽宽 16px。优先中文阅读与 CTA 点按。

Tablet

768-1199px · 8 栏 · 槽宽 24px。保留图文层级，不简单压缩桌面版。

Desktop

1200px+ · 12 栏 · 槽宽 32px。宽留白建立秩序，可局部偏移构图。

触控目标不小于 44×44px；正文行宽建议 28-38 个中文字符。

Iteration Guide 迭代指南

  1. 一次只改一个组件，引用它的 YAML 键
  2. 状态作为独立条目维护，例如 button-primary-active
  3. 任何地方都用 token 引用，不要内联 hex
  4. 需要强调时先放大字号，本规范不提供字重变化
为良禽佳木生成一版高端中文家居视觉方向：quiet luxury，暖中性色底，低饱和 taupe 强调，编辑式留白，
克制的宋体标题配现代中文无衬线正文，真实木 / 石 / 布 / 皮革材质，低文字密度。
避免电商促销感、高饱和色块、玻璃拟态、假奢华与英文优先的模板腔。

Known Gaps 已知缺口

标志尺寸：两个 logo 已按图形边界裁切（横向 678×188，纵向 568×419），可直接按高度排版；最小尺寸与安全边距的正式数值仍待品牌方确认，确认前以可见字高不低于 24px 为准。
深色主题：本规范只定义浅色底与深色区块，没有完整的深色主题令牌；需要时先补令牌，不要临时调色。
字体字重：随包字体各自只有一个字重（Swei Sugar 为 ExtraLight，OPPO Sans 为 Regular），因此规范不声明字重；需要多字重时先补字体文件。

Brand Mark & Logo 标志

横向标志：页头、页尾、品牌签名区、横向落款。

纵向标志：竖版品牌页、封面或纵向签名场景。

用法

  • 默认不插入 logo，只有用户明确要求时才使用
  • 必须使用 assets/brand/ 的真实 SVG，PNG 仅作降级
  • 颜色即 #9E7F63，直接使用文件颜色，不重新上色
  • 可见字高不低于 24px，四周净空不小于可见高度的 1/4
  • 禁止拉伸、描边、加浮雕发光、改字距、旋转、叠在高噪声图像上
