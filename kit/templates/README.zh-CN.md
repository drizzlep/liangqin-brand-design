# 页面模板

这两个页面是**骨架**，不是成品。用途是让不同的人、不同的 AI 做整页时落在同一个结构里。

| 文件 | 承载 | 结构 |
|---|---|---|
| `homepage.html` | 官网首页 | nav → hero → 材质与工艺 → 案例 → 服务方式 → 咨询 CTA → footer |
| `product-detail.html` | 产品详情 | nav → 产品首屏（图 + 标题 + 简述 + CTA）→ 规格表 → 材质与工艺 → 案例与报价 → 咨询 CTA → footer |

## 怎么用

1. 复制模板，替换文案与图片。
2. **不要改**间距、颜色、字号、圆角、模块顺序。要改就先改 `DESIGN.md` 与 `kit.css`，再回来改模板。
3. 所有「待确认」处必须由真实资料替换；没有资料就保持占位，不要编造参数、报价或案例。
4. 改完运行校验，必须 0 失败：

```bash
python3 scripts/check_page.py kit/templates/homepage.html
```

## 为什么是这两个

首页和产品详情是重复出现最多的两类页面，也是最容易被各个 AI 排出不同结构的页面。案例页、报价卡、长图暂时没有模板；等这三条跑顺了再加。
